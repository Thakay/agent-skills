# Maintaining this collection

Keep distributed skills independent of any individual's machine, account, private project, or task system. User profiles belong outside the repository and installed skill directories. Generic examples use placeholders.

Maintain the documented profile contract when changing a skill. Preserve explicit invocation and project ownership rules. A profile customizes the workflow; it does not grant additional permissions.

Run `node --test` and `node tools/verify-distribution.mjs` before committing. Review every staged file for personal information and private integration details. Use explicit staged paths. Do not publish the repository or change visibility as part of a routine update.
